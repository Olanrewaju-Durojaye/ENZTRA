# Security policy

## Supported versions

Security fixes are developed for the latest stable v1 release.

## Reporting a vulnerability

Please report vulnerabilities privately through the repository's GitHub
security-advisory feature. Do not include credentials, unpublished biological
structures, proprietary sequences, or other sensitive research data in a
public issue.

ENZTRA launches configured third-party executables and containers. Review the
displayed commands, obtain software and model weights from trusted upstream
sources, and run untrusted PDB, FASTA, configuration, pickle, or TRB files only
in an appropriately isolated environment.
